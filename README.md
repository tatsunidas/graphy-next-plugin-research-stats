# Research Stats（GRAPHY-Next プラグイン）

radiomics の研究で、特徴量の表と臨床データを結合してデータセットを作り、**調べたい問いに合わせた解析スキル**を実行するためのプラグインです。研究用で、診断・治療の判断には使いません。

## いまできること

メイン画面の「Plug-Ins」メニューの「Research Stats」から開きます。

画面は番号つきの区画（① ファイル → ② データセットの確認 → ③ 解析の種類と設定 → ④ 実行 → 結果）で、前の区画が済むまで次の区画は使えません（理由を 1 行で出します）。

1. **ファイルを選ぶ**: 特徴量の CSV（複数可。同じ見出しの表は行を連ねます）、臨床の CSV（1 行 = 1 患者）。治療前後の変化率を使うときは、2 つの時点の特徴量の CSV。選んだファイルは名前・行数・列数を一覧に出し、1 つずつ取り消せます（複数のファイルは足していけます）。
2. **データセットの確認**（解析の種類とは独立）: ID の列を、読み込んだ表の見出しから選びます。特徴量の表の各列 × 臨床の表の各列で値の重なりを数え、**重なりが最大の組**を初期値にします（同点のときだけ列名からの推測。小数を含む数値の列は ID の候補から外します）。上位の組と重なりの件数を表で見せ、組を切り替えられます。結合できた人数、片方の表にだけいる患者の一覧、欠損のある列を確かめます。次を警告します: どの組にも重なりがない／使っている組より重なりが大きい組がある／大文字小文字・全角半角・空白・ゼロ幅文字だけが違う ID（結合は完全一致のままなので、結合されません）／両方の表に同名の列がある（結合の曖昧さとリークの疑い）。結合できた人数が 0 の間は先へ進めません。結合済みデータセット（ID と特徴量）・方法の文・再現情報はこの区画から書き出せます。再現性の解析は臨床の表を使わないので、この区画では行 ID の列だけを選びます。
3. **解析の種類と設定**: 解析の種類を選ぶと、その解析に必要な目的変数だけを、**臨床の CSV の見出しから**選びます（予後: 時間・イベント・共変量／判別: 結果ラベルと陽性ラベル／予測モデル: 二値なら結果ラベル、生存なら時間・イベント／予後モデル: 時間・イベント）。選んだ列の型はその場で検査して出します（時間: 正の数・欠損・不正な値の数／イベント: 0・1・欠損・それ以外／結果ラベル: 異なる値と人数、2 値でなければ警告／共変量: 数値か・欠損数）。選んだ解析で使わない役割の列は、実行に渡しません。詳細な設定は既定で閉じています。
4. **実行して書き出す**: 結果の表・図のほか、「方法」の文、再現情報（JSON: 版・乱数シード・入力ファイルの SHA-256・設定）。（解析の種類を表すキーは `skillId`。以前の版が書き出した記録では `recipeId`）

**2D の単位を選んだ一括抽出の表**（`roi-features-batch.csv`）は、同じ症例（`CaseLabel`）の行が複数になります（列 `Unit`＝WHOLE_3D・MAX_SECTION_2D・SLICE_2D、`PlaneSource`、`Plane`。一意なのは `RowKey`）。行の ID は `RowKey`、患者の列は `PatientID` などを自動で選びます。② の「解析に使う単位」で、列ごとに実際の値（件数つき）を選びます。既定は、`Unit` に `WHOLE_3D` があればそれだけ、それ以外は全部の値です。選んだ結果、同じ患者に複数の行が残るときは、欠損を除く平均で患者ごとに 1 行にまとめ（注意帯に行数を出します）、絞り込み（列・値）と平均した行数の範囲は「方法」の文と再現情報に残ります。1 行も残らない選び方は先へ進めません。

同じ患者に複数行が残るとき、② に「行の扱い」が出ます（`rs-rows-mode`）。**患者ごとに平均する（既定）**か、**行のまま解析する（患者単位でグループ化）**かを選べます。「行のまま」は **P4（予測モデル）だけ**で、③ で P4 を選んだときに有効になります（ほかの解析に切り替えると平均に戻ります）。R1・R2・R5 で選べない理由は画面に出します。同じ患者の行は独立でないため、特徴量ごとの検定（R1・R2）や Cox の標準誤差（R1・R5）が過大に有意になるからです。R5 は、ブートストラップと LASSO の分割が行単位で、患者単位（クラスターのブートストラップ）にするのは別の大きな変更になるため、今回は対象外です。

- 「行のまま」の P4: 1 行 = 1 観測、患者 = グループ。交差検証の外側・内側（LASSO の λ を選ぶ分割を含む）とテスト集合の分離（固定ファイル）は**患者単位**（同じ患者の行は必ず同じ側）で、層化は患者の結果（二値のラベル・生存のイベント）で行います。固定ファイルの ID・件数・指紋は患者の単位です（`unit: "patient-grouped-rows"`）。
- 性能（AUC・C-index。外側の分割ごと・予測を束ねた値・テスト集合）は、**行ごとの予測を患者ごとに平均した予測**で評価します（1 患者 = 1 点。行の数で n を水増ししません）。LASSO の λ を選ぶ内側の交差検証の損失は行単位の偏差のままです（分割だけが患者単位）。
- 報告には、使った行数・患者数・患者あたりの行数の範囲を出します。データリーク検査の「同じ患者が訓練と検証に分かれていないか」は、行のままのときは分割の割り当てから実際に検査します（OK／NG を記録）。
- 分散 0・相関・p 値による除外・特徴量の順位付け・当てはめは、行を単位に計算します（行数は増えますが、同じ患者の行は独立でないため、対応なしの p 値は小さく出やすく、相関は患者内の類似を含みます）。画面に注意を出しますが、止めてはいません。
- 選んだ方法は実行記録（`rowsMode=asis`。平均のときは設定に何も載せません）と「方法」の文に残ります。既定（平均）の実行は、記録がバイト単位で従来と同じです（`test/rowsAsIsGolden.test.ts`）。

**データリークの検査**（しきい値は使わず、定義で決まる条件だけで判定します）:

- ② 特徴量に混ざった ID・由来・記録の列: 名前が `Provenance_`・`Warning_`・`Roi_`・`Row`・`Filter_`・`Diagnostics_` で始まる、`Unit`・`PlaneSource`・`Plane`・`RowKey`・`CaseLabel`・`PatientID`・`SubjectCode`・`Album` に一致する、`UID` で終わる、名前に `Date`・`Time` を含む列、および、ファイルの行の順に整数が公差一定（0 でない）で厳密に単調に並ぶ列（1,2,3,… ／ 10,20,30,… ／ 5,4,3,…。行番号・連番の疑い。欠損・空・小数のある列と 3 行未満は対象外。整数で全部異なっていても、順序がばらばらなら当たりません）。既定の選択が既に除いている列は「除外済み」と分け、使っている列だけを警告にして、「特徴量から外す」を選べます。
- ③ 目的変数の混入（役割を選んだあと、その解析で使う列だけ）: 特徴量が、結果ラベル・時間・イベントと同名／値が完全に一致／結果（イベント）を完全に分ける（AUC が正確に 1 か 0。各群 2 人以上）／時間と順位が完全に一致（|ρ| が正確に 1）のとき警告し、特徴量から外せます。両方の表の同名の列も、役割の列なら混入として警告します。
- 結果（予測モデルの性能・予後モデル）: 同じ患者が訓練と検証に分かれていないかを、**実際の分割の割り当て**から検査します（外側・内側の交差検証、開発集合とテスト集合の重なり。予後モデルでは LASSO の交差検証の分割）。さらに前処理（補完・順位付け・標準化・当てはめ・品質管理）が推定に使った行を記録し、実行後に**訓練側の行だけか**を検査します（外側の分割・内側の分割・最終モデル）。判定は 3 段階です。**OK**: 全ステップが訓練側の行だけを使った。**注意**: 教師なしのステップ（補完・品質管理）だけが、訓練側でない行の値を読んだ（結果ラベルは使っていない。どのステップが何分割で読んだかを出し、実行は止めません）。**NG**: 目的変数を使うステップ（順位付け・当てはめ・特徴量選択）が訓練側でない行を使った。品質管理（値が 1 種類・相関）は結果ラベルを使いませんが開発集合全体の行を読むため、有効にすると「注意」になります（交差検証の前に 1 回行う設計）。結果は再現情報と「方法」の文に残ります。

守っていること:

- 欠損は 0 で埋めません。複数病変の平均は欠損を除いて求め、すべて欠損なら欠損のままです。
- 片方にしかいない患者は黙って捨てず、一覧に出します。患者 ID・病変 ID の重複、イベントが 0・1 でない値、時間が正でない値は、直さずに止めます。
- 同じ入力・設定・乱数シードなら、記録も「方法」の文も同じになります。

## スキル「予後との関係」

特徴量が生存と関係するかを、特徴量ごとに調べます。

- 群の分け方: 中央値（既定）／指定した値／三分位／最適しきい値（log-rank のχ²が最大の値）。最適しきい値は**探索的**で、素の p は探索のぶん小さく出るため、時間とイベントの組を並べ替える検定で補正した p を併記します。各群に残す最小の割合（既定 10%）は実装上の仮定です。
- 各特徴量: Kaplan–Meier 曲線（Greenwood の分散、log(−log) の信頼区間、リスク表）、log-rank 検定、Cox 比例ハザードモデル（同時刻は Efron の近似。群の HR と、標準化した連続値の SD あたり HR）、任意で RMST の差と Mann–Whitney。
- **層に分けられない特徴量は、解析の前に QC で除きます**（同じ値が多くて指定した群数に分けられない、人数が足りない、など）。除いた特徴量と理由は、実行の警告・結果の表の「理由」の列・書き出し（`qc_excluded`）に出ます。
- **群に死亡が無いとき**、群の HR は発散して推定できません。この場合は HR を「推定不能（群 k に死亡なし）」と記録し（書き出しは `hr_group_note`）、log-rank の p・q は有効なので、特徴量は選択の対象に残します。
- 多重比較: Benjamini–Hochberg 補正（既定）。補正しない探索的な解析は、明示して選びます。
- 多変量: 基準を満たした特徴量と共変量で Cox モデル。**入れる変数の数は、イベント数 ÷ 10（変数 1 個あたりイベント 10 件。Peduzzi ら 1996）までです**。共変量を先に数え、残りの枠に p の小さい順で特徴量を入れ、入れなかった特徴量は結果の注記に名前を出します。枠が無ければ、多変量モデルは作らず、特徴量ごとの結果だけを返します（多変量が作れなくても、Skill は失敗にしません）。臨床因子だけのモデルとの −2 log 尤度の差、C-index、ブートストラップで楽観を補正した C-index（特徴量の選択も毎回やり直します）。
- 書き出し: 特徴量ごとの結果、KM の点列（図を作り直せる数値）、「方法」の文、再現情報。

守っていること: 計算できなかった特徴量は理由を表に出し、p や q は空欄のままにします（0 や 1 にしません）。収束しない・完全分離の Cox は、数値を出さずに理由を出して止めます。

C-index（Harrell）は lifelines の `concordance_index` と同じ定義です。同じ時刻の組は、片方がイベントで片方が打ち切りなら数え（イベントが先）、イベント同士は数えません。予測が同点の組は 0.5 です。

限界: 比例ハザードの仮定は検査していません。多変量モデルの共変量は数値の列だけです（カテゴリは 0/1 などに直してください）。実行が重い設定（最適しきい値 × 多数の特徴量）は、進み具合を出し、取り消せます。

## スキル「2 群の判別」

結果ラベル（2 種類）を、特徴量で判別できるかを調べます。陽性とするラベルは**必ず選んでください**（既定は決めていません）。

- 特徴量ごと: ROC・AUC（DeLong 法の 95% 信頼区間。向きは AUC が 0.5 以上になる側）、Mann–Whitney、Benjamini–Hochberg 補正、しきい値（診断精度最大 または Youden 指数最大）での感度・特異度・陽性的中率・陰性的中率・精度（Clopper–Pearson の正確な 95% 信頼区間）、混同行列。
- 組み合わせ: 基準を満たした上位 k 個（既定 2）を標準化してロジスティック回帰で組み合わせ、leave-one-out（LOO）で検証します。**特徴量の選択も各折の内側でやり直します**（外でやると、ランダムなラベルでも AUC が 0.5 を大きく超えるため）。基準を満たす特徴量が 1 つも無い折は、訓練データの陽性割合をそのまま予測にします。この折の数は結果に出します（除いた患者が陽性だと訓練側の陽性割合が下がるため、この折が多いと LOO の AUC は 0.5 より低く偏ります）。較正（分位ビン。平滑化はしません）と決定曲線（純便益）も LOO の予測で出します。
- 決定木（任意）: 各節点で、その枝に残った症例の診断精度が最大になる特徴量・向き・しきい値を選び、枝の誤分類率が 15% 未満なら止めます。信頼区間は、各節点の感度・特異度の不確かさを木に伝えるモンテカルロ（既定 1000 回）の 2.5・97.5 パーセンタイルです。性能は木を作った同じ患者での値で、検証していません。
- 書き出し: 結果表、ROC・較正・決定曲線の点列、決定木、「方法」の文、再現情報。

論文に書かれていないため本実装で置いた仮定: 組み合わせの方法（ロジスティック回帰）、AUC の信頼区間（DeLong）、モンテカルロの抽出分布（各節点の二項データ由来の Beta 分布）、決定木の節点の最小症例数（5）と最大の深さ（6）、分けても精度が上がらない枝は分けない。

## スキル「条件を変えても同じか（再現性）」

ソフト・設定・再構成などの条件を変えて作った特徴量の表（**1 ファイル = 1 条件**、2 つ以上）を、行 ID で突き合わせて、特徴量ごとの再現性を調べます。臨床の CSV は要りません。

- ICC: 二元配置（症例 × 条件）の分散分析から、absolute agreement の ICC（単一測定。平均測定も併記）と 95% 信頼区間（McGraw–Wong の F 近似）。two-way mixed と two-way random で同じ値です。負の値は 0 に切ります。
- 区分: 信頼区間の**下限**が 0.5 未満 poor、0.75 未満 moderate、0.9 以下 good、0.9 超 excellent（境界の等号と「下限で決める」ことは論文に明記が無く、本実装で決めました）。
- 定数のずれ（条件 B が A + 定数）があると、相関は 1 でも ICC は下がります（consistency ではなく absolute agreement）。
- Bland–Altman: 選んだ特徴量・2 条件の差（B − A）の平均（バイアス）と、一致限界（±1.96 SD）とそれぞれの 95% 信頼区間。
- 欠損は 0 にしません。その特徴量では欠損のある行を除き、除いた数を表に出します。全条件に揃っていない行、使えなかった列（一部の条件にしか無い、数でない値）は理由つきの一覧で出します。
- 除外候補: 基準（moderate / good / excellent より低い）を選んだときだけ、該当する特徴量の一覧（CSV）を書き出します。基準は既定では選びません。

## スキル「予測モデルの性能（P4: 入れ子の交差検証・テスト集合）」

特徴量から作ったモデルが、**作るのに使っていない症例**でどのくらい当たるかを見積もります。結果は二値（ロジスティック回帰と AUC）か生存（Cox と Harrell の C-index）です。

- **既定値の無い設定**: 結果の型、テスト集合の扱い、テストの割合、外側・内側の分割数、使う特徴量の数の候補、生存での層化、欠損の扱い（欠損があるとき）。推奨値を書いた文献が無いため既定値を置かず、入れるまで実行しません。**既定値があるもの**（利用者の指定。2026-11-26）: 外側の反復回数 1、勾配ブースティングの学習率 0.1、相関のしきい値 0.9（**相関による除外は、既定で有効**です。空欄にすると行いません。相関のしきい値は R1・R2 の前処理と設定を共有するので、Skill を切り替えるとその Skill の既定（P4 は 0.9、ほかは空欄）に戻ります）。外側の反復を 1 にすると計算は軽くなりますが、症例が少ないときは分割の取り方による値のばらつきが大きいので、確かめたいときは反復を増やしてください。画面には文献での使用例を出典つきで示します。
- **テスト集合**: 標準化・特徴選択・モデル選択の**前に**分け（二値は結果、生存は選べばイベントで層化）、**固定ファイル**（JSON）に記録します。固定ファイルは対象の症例（ID と結果）の指紋とテスト症例を持ち、違うデータや手で書き換えたファイルは読み込みません。テスト集合での評価は、保存した固定ファイルを読み込んでから**別のボタン**で行い、評価のたびに回数を 1 増やした固定ファイルを保存します。2 回目以降は警告します。
  - 限界: 古い固定ファイルを読ませれば回数は戻ります。誤用は防げますが、改ざんは防げません。報告の回数は最新のファイルで確かめてください。
- **品質管理**（任意。**開発集合の値だけ**を使う）: 値が 1 種類の特徴量、|Spearman の ρ| がしきい値以上の組の片方（欠損の少ない方、同じなら列の順が先の方を残す。残し方は本実装で決めました）、再現性のスキルの除外候補 CSV にある特徴量を除きます。
- **欠損**: 0 では補いません。欠損のある症例を除く（一覧を出す）か、各訓練分割の中央値で補うかを選びます。
- **入れ子の交差検証**: 外側の分割（層化）× 反復、内側の分割（層化しない）。補完・特徴量の順位付け（二値は Mann–Whitney の p、生存は単変量 Cox の p）・標準化・当てはめは、すべて**その訓練分割の中だけ**で行い、使う特徴量の数を内側の交差検証で選びます（二値は予測を束ねた AUC、生存は分割ごとの C の平均が最大。同じなら少ない方。この選び方は本実装で決めました）。
- **報告**: 外側の分割ごとの値の平均・最小・最大、二値では予測を束ねた AUC。交差検証の値には**信頼区間を付けません**（分割の間の相関のため、素朴な区間は狭すぎる）。テスト集合の値には、AUC は DeLong 法、C-index はブートストラップのパーセンタイルの 95% 信頼区間を付けます。症例数と特徴量の数の比を出し、特徴量の方が多いときは警告します。
- **最終モデル**: 開発集合全体での交差検証で特徴量の数を選び、開発集合全体で作り直します。入れ子の交差検証の値は「この手順全体」の性能の見積もりです。
- **モデルに LASSO も選べます**（二値はロジスティック、生存は Cox。同時刻は Breslow）。このとき内側の交差検証で選ぶのは、特徴量の数ではなく λ です。λ の列と標準化は、その訓練分割だけで求め、偏差が最小か 1SE 規則で選びます（選び方は既定値なし）。係数が 0 でない数が、Cox ではイベント数、二値では症例数 − 1 に達したら、それより小さい λ は解きません（解が一意に決まらない領域）。
- **結果の型で選べるモデルが変わります**（型を選ぶまでは、どちらでも使える「上位 k 個」と LASSO だけ。型に合わないモデルは選択肢に出ず、実行も検証エラーで止まります）。**二値の結果では、ランダムフォレスト・SVM（RBF カーネル）・勾配ブースティングも選べます**。使える特徴量をすべて使い（特徴量の選択はしません）、利用者が入れた候補の組み合わせ（RF: 木の数と mtry、SVM: C と γ、勾配ブースティング: 段数・深さ・学習率・subsample）から、内側の交差検証（予測を束ねた AUC が最大、同じなら先の組）で選びます。読んだ論文に設定が無いため既定値は置かず、画面に scikit-learn 1.9 の既定を使用例として出します。実行の前に当てはめの回数を表示します。
  - 計算は scikit-learn 1.9 と同じ定義の自前の実装です（外部のライブラリは使っていません）。乱数を使わない設定では sklearn と値が一致し、乱数を使う設定では 20 シードの AUC の分布が一致することを試験で確かめています（`tools/gen_ml_fixture.py`）。決定木の分岐で改善量が同点のときの選び方と乱数列は sklearn と違います。
  - SVM の出力は決定値で、確率ではありません。較正の図は出しません。特徴量は訓練分割の平均・SD で標準化し、γ の scale も標準化した訓練分割から求めます。
  - ランダムフォレストと勾配ブースティングは、最終モデルの重要度（不純度の減少、合計 1）を表と CSV に出します。
  - 生存の結果では選べません（生存で選べるモデルは次の項目）。
- **生存の結果では、次のモデルも選べます**（使える特徴量から選び、予測はリスク＝線形予測子。評価は外側の分割ごとの Harrell の C-index）。
  - **Elastic Net（Cox）**: L1 と L2 の罰則を混ぜます（−(1/n)·対数部分尤度 + λ[α‖β‖₁ + (1−α)/2·‖β‖²]、同時刻は Breslow）。L1 の比率 α は 0 より大きく 1 より小さい値を入れます（既定値なし。1 は LASSO、0 は Ridge を選びます）。λ の列・選び方は LASSO と同じです（最小の λ の比と λ の選び方は同じ規則）。
  - **Ridge（Cox）**: L2 罰則だけ（α = 0）。係数が 0 になる特徴量は無く、使える特徴量はすべてモデルに入ります。λ の列は、glmnet と同じく α = 0.001 の λmax から作ります。L2 を混ぜると解が一意になるので、LASSO の「係数が 0 でない数がイベント数に達したら止める」規則は使いません。
  - **Cox ブースティング**: R5 と同じ実装（成分ごと・尤度ベース・線形の基底、同時刻は Breslow）。反復回数の候補（既定値なし）を内側の交差検証（分割ごとの C-index の平均が最大、同じなら先の候補）で選び、学習率 ν は既定 0.1 です。係数が 0 でない特徴量が使われ、最終モデルの変数重要度（減った −対数部分尤度）を書き出します。
  - 検証: Elastic Net・LASSO は scikit-survival の `CoxnetSurvivalAnalysis`、Ridge は同じ目的関数を Newton 法で解く自前の参照と、固定した λ での係数を突き合わせています（`tools/gen_enet_fixture.py`。こちらの目的関数が参照より悪くないことと、係数の差が 5e-6 以内であることを試験で確かめています）。
- 書き出し: 分割ごとの結果、交差検証の予測、選ばれた回数、除いた特徴量・症例、固定ファイル、「方法」の文、再現情報。

ランダムなラベルとランダムな特徴量では入れ子の AUC は 0.5 付近に、分割の前に全データで特徴量を選ぶ（漏れのある）やり方では 0.7 を超えることを、試験で確かめています。

## スキル「少数の特徴で予後モデル」

生存（または無増悪生存など）を少数の特徴量で予測するモデルを、論文（Salazar ほか 2024）の手順で作ります。

1. **相関で冗長を除く**: 値が 1 種類の特徴量と、|Spearman の ρ| がしきい値以上の組の片方を除きます（残し方は P4 と同じ）。欠損のある特徴量は使わず、一覧に出します。
2. **候補を絞る**: 次のどちらかを選びます。
   - **Cox ブースティング**（成分ごと・線形の基底、同時刻は Breslow。係数が 0 でない特徴量を、変数重要度＝減った −対数部分尤度の順に並べる）。論文で使われた R の mboost と**同じ値になるとは言えません**（論文に式が無く、R での照合もしていません）。
   - **LASSO-Cox**（同時刻は Breslow。λ は交差検証の部分尤度の偏差で、最小か 1SE 規則で選ぶ）。
3. **後退選択**: 多変量 Cox（Efron）の Wald の p が出る p を超えたら除き、除いた変数は入る p 未満なら戻します。最大の数を超えたら p の大きい順に除き、そのことを表示します。
4. **補正 C-index**: Harrell のブートストラップで楽観を補正します。各回で**手順 1〜3 をすべてやり直します**。あわせて、**ブートストラップに入らなかった患者（OOB。1 回あたり約 37%）での C-index** の平均を出します（モデルが見ていない患者での値）。補正 C-index との差が大きいときは、楽観が残っています。**最終モデルが特徴量を使わない（0 個）ときは、補正 C-index を計算しません**（定数モデルの見かけの C は 0.5 で、特徴量を使う標本の楽観を引くと 0.5 を下回る意味のない値になるため。注記に出します）。
5. **比例ハザードの確認**: スケールした Schoenfeld 残差の図と、Grambsch–Therneau の検定（時間は 1 − Kaplan–Meier）。R の survival 3.x の `cox.zph` とは式が違うため、同じ値にはなりません。p が小さい変数は警告しますが、時間で層別した解析はしません。

- 既定値は論文にあるものだけです（100 反復、入る P<0.1・出る P>0.15、予測変数は 5 未満、ブートストラップ 2000 回）。相関のしきい値（0.9）と学習率 ν（0.1）は論文に無いので、利用者の指定（2026-11-26）で既定に入れています（空欄にすると実行しません）。λ の選び方は論文に無いので既定値を置かず、入れるまで実行しません（LASSO のとき）。
- LASSO-Cox で 2000 回のブートストラップを行うと、数分〜十数分かかることがあります（実測: 120 人・15 特徴量で、交差検証 1 回が約 0.3 秒）。
- 書き出し: モデル（係数・HR・標準化の平均と SD・C-index）、選択の経過、絞り込み（重要度または λ ごとの偏差と係数）、Schoenfeld 残差、「方法」の文、再現情報。

**補正 C-index の限界（標本が小さいとき）**: 患者 100 人・イベント約 70 件・特徴量 40 個のランダムな特徴量では、補正 C-index は 0.5 付近になり、ブートストラップで選択をやり直さない（漏れのある）やり方では過大になることを、試験で確かめています。**しかし、イベントが少なく特徴量が多いと、補正後も 0.5 を大きく超えます**。NSCLC 56 例（イベント 15 件・特徴量 168 個）で時間とイベントの組を患者の間で入れ替え（特徴量と生存の関係を壊し、本来は 0.5）、独立に書き直した手順で 40 回調べると、補正 C-index は平均 0.63（SD 0.07、範囲 0.50〜0.78）でした（本体の実装 9 回: 平均 0.60）。特徴量を乱数にした合成データ（特徴量 168 個）では、イベントが約 15・30・60 件で平均 0.72・0.63・0.56 と、増やすほど 0.5 に近づきます。
原因は、Harrell の補正が、ブートストラップで作ったモデルを**元のデータ全体**で評価することです。元のデータには、そのモデルの訓練に使った患者（約 63%）が含まれるので、過学習が強いと楽観を取りきれません。同じモデルを、ブートストラップに入らなかった患者だけで評価すると平均 0.49 で、ほぼ 0.5 でした（この値を OOB の C-index として結果に併記します）。したがって、**イベントが少ないとき（目安: 変数 1 個あたり 10 件を大きく下回る）の補正 C-index は、楽観が残った値として読み、P4（入れ子の交差検証）の値と合わせて判断してください**。
LASSO（Cox）は statsmodels、Schoenfeld 残差は statsmodels、後退選択の各段の Cox は statsmodels（Efron）と照合しています。上の独立した書き直しは `tools/verify_real/r5_ref.py`（元データでは、見かけの C-index が本体と全桁一致）。

予後・判別・再現性・予測モデルの性能・予後モデル以外のスキル（ランダムフォレストなど）は、今後のバージョンで加えます。

## 前処理の統計部品（`src/core/stats/`。組み込みは次の節「前処理の区画」）

外部の統計ライブラリを使わない純関数です。

- 正規性: Shapiro–Wilk（`shapiro.ts`。Royston 1995 の AS R94、3 ≤ n ≤ 5000。全値が同じなら p は null＝計算できない）。
- 等分散性: Levene（中心 mean）／Brown–Forsythe（中心 median、既定）（`levene.ts`。2 群以上）。
- 平均の比較: Student・Welch・対応のある t（`ttest.ts`。両側）。順位の比較: Wilcoxon の符号順位（`wilcoxon.ts`）と、既存の Mann–Whitney。
  - Wilcoxon は scipy の既定（0 差を除く・連続性補正なし・auto）と同じ定義です。0 差もタイも無く組が 50 以下なら正確な分布（`exact`）、0 差かタイがあり 13 組以下なら符号の全割り当て（`permutation`）、それ以外は正規近似（`approx`）で、使った方法と除いた 0 差の数を返します。差がすべて 0 のときは p を計算できない（null）とします（scipy は 1 を返す）。
- 検定の選び方（`assumptions.ts`。α は引数で、既定値はありません）:
  - 対応なし 2 群: 各群の Shapiro–Wilk の p が両方とも α 以上（各群 3 個以上）なら「正規」。正規で Levene（median）の p が α 以上なら Student、正規で等分散でない（Levene が計算できない場合を含む）なら Welch、正規でない（検定できない場合を含む）なら Mann–Whitney。
  - 対応あり: 差の Shapiro–Wilk の p が α 以上（3 組以上）なら対応のある t、そうでなければ Wilcoxon の符号順位。
  - 戻りに、選んだ検定・統計量・p・前提の検定の結果・理由（日本語・英語）を持ちます。
- 列の選択（`dropByPValue.ts`）: 列ごとに上の規則で検定し、p が**しきい値以上**または計算できない列を落とします。対応なしは群ごとの行、対応ありは行の組を渡し、渡した行だけを読みます（しきい値・α は引数）。落とした理由は列ごとの記録に残ります。
- 標準化（`standardize.ts`。平均・SD の算術 `meanSd` は P4 のパイプライン・LASSO・Cox ブースティングと共通）: 平均と標本 SD（n − 1）を与えた行だけから推定し、別の行に適用します。SD が 0 の列は適用不可（0 で割らない）。`needsStandardization(model)` は、尺度に敏感なモデル（lasso・svm・logistic・knn）は true、決定木・ランダムフォレスト・勾配ブースティングは false です。

参照値は `tools/gen_preprocess_fixture.py`（scipy の `shapiro`・`levene`・`ttest_ind`・`ttest_rel`・`wilcoxon`・`mannwhitneyu` と、選び方の規則を scipy の関数で書き直したもの）が `test/fixtures/preprocess.json` に出し、`test/preprocess.test.ts` が突き合わせます（固定シードの正規・対数正規・外れ値・タイ・小標本から n = 5000 まで、差が 0 のペア、分散の違う 2 群）。Shapiro–Wilk だけは scipy の数値の近似の精度に合わせて許容を広げています（W 1e-8、p 絶対 1e-7）。

## 前処理の区画（③の次。R1・R2・P4・R5。R3 には出ません）

解析の種類を選ぶと、その種類で使える前処理だけが出ます（使えない手順は出しません）。**既定はすべてオフ**で、何も有効にしなければ従来と完全に同じ結果です。しきい値・α に既定値はありません（利用者が入れます）。各項目の ⓘ に説明があります。

| 手順 | R1 | R2 | P4 | R5 |
| --- | --- | --- | --- | --- |
| 分散 0 の除外 | ○ | ○ | ○ | 常に行う（手順の中で、ブートストラップごと） |
| 相関しきい値による除外（Spearman、\|ρ\| ≥ しきい値） | ○ | ○ | ○ | ○（必須） |
| 標準化 | – | – | 自動（必要かを表示） | 自動（LASSO・ブースティングとも、実装が訓練の行で標準化する） |
| 正規性・等分散性の検定の報告 | – | ○ | ○（二値） | – |
| p 値による除外（対応なし） | – | – | ○（二値。交差検証の各訓練の行の内側） | – |
| p 値による除外（対応あり） | ○ | ○ | ○ | ○ |

- 分散 0・相関の除外は目的変数を使わないので、患者ごとの特徴量の行列（P4 は開発集合）の全行から決めます（データリーク検査では「注意」）。除いた特徴量と理由は結果の画面と実行記録（手順 `pre`、P4 は `p4-qc`）に残り、R1・R2 では多重比較の補正の対象の数 m が除外の後の特徴量で数えられます。
- **正規性・等分散性の報告**: 特徴量ごとに、2 群それぞれの Shapiro–Wilk（W・p・n）と Levene（median）の p、選ばれる検定（Student・Welch・Mann–Whitney）とその理由を表にし、`research-stats-assumptions.csv` に書き出せます。報告だけで結果は変えません。計算できない値は空欄で理由を付けます。R2 の既存の検定（Mann–Whitney・DeLong）は変えていません。
- **p 値による除外（対応なし。P4・二値）**: 目的変数を使うので、外側の各訓練の行・内側の各訓練の行（LASSO の λ を選ぶ分割を含む）・最終モデルの開発集合のそれぞれで、その訓練の行だけを使って検定し、p がしきい値以上（または検定できない）特徴量をその訓練の中で使わないことにします。検証側の行は読みません。除外は折ごとに記録し（結果の画面と `research-stats-p4-pdrop.csv`）、データリーク検査では目的変数を使う段階 `pdrop` として「訓練側だけ」を確かめます。検定の回数は（外側 × 反復 + 1）×（内側 + 1）組 × 特徴量の数です（画面に目安を出します）。
- **p 値による除外（対応あり）**: 前と後の表の両方を読み込んだときだけ出ます。患者ごとの「前の値」「後の値」（変化率と同じ順序の定義。`lesion-then-mean` は前後の両方がそろった病変を患者で平均、`mean-then-change` は患者で平均した前・後）を特徴量ごとに対にし、差の Shapiro–Wilk で対応のある t か Wilcoxon の符号順位を選び、**時点間で有意な変化の無い（p ≥ しきい値）特徴量を除きます**。目的変数は使いませんが全患者の値を読むので、データリーク検査では「注意」です（P4 は開発集合だけを読みます）。
- 検証: 対応なし・対応ありとも、`tools/gen_preprocess_pipeline_fixture.py`（scipy 1.15.3 で規則を独立に書き直し、同じ合成データ・同じ訓練の行・複数の（α、しきい値）で残る特徴量の一覧を出す）が `test/fixtures/preprocess_pipeline.json` に書き、`test/preprocessPipeline.test.ts` が突き合わせます。

## 変化率

変化率 = (後 − 前) / |前| × 100（%）。病変ごとに求めて患者で平均する方法（既定）と、患者で平均してから求める方法を選べます。基準値が 0 の値は欠損にします。結果には患者ごとの前の値・後の値（対応のある検定用）も持ちます。
