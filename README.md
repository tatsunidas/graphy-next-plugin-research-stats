# Research Stats（GRAPHY-Next プラグイン）

radiomics の研究で、特徴量の表と臨床データを結合してデータセットを作り、**調べたい問いに合わせた解析スキル**を実行するためのプラグインです。研究用で、診断・治療の判断には使いません。

## いまできること（0.5.0）

メイン画面の「Plug-Ins」メニューの「Research Stats」から開きます。

1. **ファイルを選ぶ**: 特徴量の CSV（複数可。同じ見出しの表は行を連ねます）、臨床の CSV（1 行 = 1 患者）。治療前後の変化率を使うときは、2 つの時点の特徴量の CSV。
2. **列を割り当てる**: 病変・ROI の識別、患者、時間、イベント（0 か 1）、結果ラベル、共変量。
3. **結合の結果を確かめる**: 結合できた患者数、片方の表にしかいない患者、欠損のある列、解析から除く患者と理由。
4. **書き出す**: 結合済みのデータセット（CSV）、「方法」の文、再現情報（JSON: 版・乱数シード・入力ファイルの SHA-256・設定）。（解析の種類を表すキーは `skillId`。以前の版が書き出した記録では `recipeId`）

守っていること:

- 欠損は 0 で埋めません。複数病変の平均は欠損を除いて求め、すべて欠損なら欠損のままです。
- 片方にしかいない患者は黙って捨てず、一覧に出します。患者 ID・病変 ID の重複、イベントが 0・1 でない値、時間が正でない値は、直さずに止めます。
- 同じ入力・設定・乱数シードなら、記録も「方法」の文も同じになります。

## スキル「予後との関係」

特徴量が生存と関係するかを、特徴量ごとに調べます。

- 群の分け方: 中央値（既定）／指定した値／三分位／最適しきい値（log-rank のχ²が最大の値）。最適しきい値は**探索的**で、素の p は探索のぶん小さく出るため、時間とイベントの組を並べ替える検定で補正した p を併記します。各群に残す最小の割合（既定 10%）は実装上の仮定です。
- 各特徴量: Kaplan–Meier 曲線（Greenwood の分散、log(−log) の信頼区間、リスク表）、log-rank 検定、Cox 比例ハザードモデル（同時刻は Efron の近似。群の HR と、標準化した連続値の SD あたり HR）、任意で RMST の差と Mann–Whitney。
- 多重比較: Benjamini–Hochberg 補正（既定）。補正しない探索的な解析は、明示して選びます。
- 多変量: 基準を満たした特徴量と共変量で Cox モデル。臨床因子だけのモデルとの −2 log 尤度の差、C-index、ブートストラップで楽観を補正した C-index（特徴量の選択も毎回やり直します）。
- 書き出し: 特徴量ごとの結果、KM の点列（図を作り直せる数値）、「方法」の文、再現情報。

守っていること: 計算できなかった特徴量は理由を表に出し、p や q は空欄のままにします（0 や 1 にしません）。収束しない・完全分離の Cox は、数値を出さずに理由を出して止めます。

限界: 比例ハザードの仮定は検査していません。多変量モデルの共変量は数値の列だけです（カテゴリは 0/1 などに直してください）。実行が重い設定（最適しきい値 × 多数の特徴量）は、進み具合を出し、取り消せます。

## スキル「2 群の判別」

結果ラベル（2 種類）を、特徴量で判別できるかを調べます。陽性とするラベルは**必ず選んでください**（既定は決めていません）。

- 特徴量ごと: ROC・AUC（DeLong 法の 95% 信頼区間。向きは AUC が 0.5 以上になる側）、Mann–Whitney、Benjamini–Hochberg 補正、しきい値（診断精度最大 または Youden 指数最大）での感度・特異度・陽性的中率・陰性的中率・精度（Clopper–Pearson の正確な 95% 信頼区間）、混同行列。
- 組み合わせ: 基準を満たした上位 k 個（既定 2）を標準化してロジスティック回帰で組み合わせ、leave-one-out（LOO）で検証します。**特徴量の選択も各折の内側でやり直します**（外でやると、ランダムなラベルでも AUC が 0.5 を大きく超えるため）。較正（分位ビン。平滑化はしません）と決定曲線（純便益）も LOO の予測で出します。
- 決定木（任意）: 各節点で、その枝に残った症例の診断精度が最大になる特徴量・向き・しきい値を選び、枝の誤分類率が 15% 未満なら止めます。信頼区間は、各節点の感度・特異度の不確かさを木に伝えるモンテカルロ（既定 1000 回）の 2.5・97.5 パーセンタイルです。性能は木を作った同じ患者での値で、検証していません。
- 書き出し: 結果表、ROC・較正・決定曲線の点列、決定木、「方法」の文、再現情報。

論文に書かれていないため本実装で置いた仮定: 組み合わせの方法（ロジスティック回帰）、AUC の信頼区間（DeLong）、モンテカルロの抽出分布（各節点の二項データ由来の Beta 分布）、決定木の節点の最小症例数（5）と最大の深さ（6）、分けても精度が上がらない枝は分けない。

## スキル「条件を変えても同じか（再現性）」

ソフト・設定・再構成などの条件を変えて作った特徴量の表（**1 ファイル = 1 条件**、2 つ以上）を、行 ID で突き合わせて、特徴量ごとの再現性を調べます。臨床の CSV は要りません。

- ICC: 二元配置（症例 × 条件）の分散分析から、absolute agreement の ICC（単一測定。平均測定も併記）と 95% 信頼区間（McGraw–Wong の F 近似）。two-way mixed と two-way random で同じ値です。負の値は 0 に切ります。
- 区分: 信頼区間の**下限**が 0.5 未満 poor、0.75 未満 moderate、0.9 以下 good、0.9 超 excellent（境界の等号と「下限で決める」ことは論文に明記が無く、本実装で決めました）。
- 定数のずれ（条件 B が A + 定数）があると、相関は 1 でも ICC は下がります（consistency ではなく absolute agreement）。
- Bland–Altman: 選んだ特徴量・2 条件の差（B − A）の平均（バイアス）と、一致限界（±1.96 SD）とそれぞれの 95% 信頼区間。
- 欠損は 0 にしません。その特徴量では欠損のある行を除き、除いた数を表に出します。全条件に揃っていない行、使えなかった列（一部の条件にしか無い、数でない値）は理由つきの一覧で出します。
- 除外候補: 基準（moderate / good / excellent より低い）を選んだときだけ、該当する特徴量の一覧（CSV）を書き出します。基準は既定では選びません。

## スキル「予測モデルの性能（入れ子の交差検証とテスト集合）」

特徴量から作ったモデルが、**作るのに使っていない症例**でどのくらい当たるかを見積もります。結果は二値（ロジスティック回帰と AUC）か生存（Cox と Harrell の C-index）です。

- **既定値の無い設定**: 結果の型、テスト集合の扱い、テストの割合、外側・内側の分割数、反復回数、使う特徴量の数の候補、生存での層化、欠損の扱い（欠損があるとき）。推奨値を書いた文献が無いため既定値を置かず、入れるまで実行しません。画面には文献での使用例を出典つきで示します。
- **テスト集合**: 標準化・特徴選択・モデル選択の**前に**分け（二値は結果、生存は選べばイベントで層化）、**固定ファイル**（JSON）に記録します。固定ファイルは対象の症例（ID と結果）の指紋とテスト症例を持ち、違うデータや手で書き換えたファイルは読み込みません。テスト集合での評価は、保存した固定ファイルを読み込んでから**別のボタン**で行い、評価のたびに回数を 1 増やした固定ファイルを保存します。2 回目以降は警告します。
  - 限界: 古い固定ファイルを読ませれば回数は戻ります。誤用は防げますが、改ざんは防げません。報告の回数は最新のファイルで確かめてください。
- **品質管理**（任意。**開発集合の値だけ**を使う）: 値が 1 種類の特徴量、|Spearman の ρ| がしきい値以上の組の片方（欠損の少ない方、同じなら列の順が先の方を残す。残し方は本実装で決めました）、再現性のスキルの除外候補 CSV にある特徴量を除きます。
- **欠損**: 0 では補いません。欠損のある症例を除く（一覧を出す）か、各訓練分割の中央値で補うかを選びます。
- **入れ子の交差検証**: 外側の分割（層化）× 反復、内側の分割（層化しない）。補完・特徴量の順位付け（二値は Mann–Whitney の p、生存は単変量 Cox の p）・標準化・当てはめは、すべて**その訓練分割の中だけ**で行い、使う特徴量の数を内側の交差検証で選びます（二値は予測を束ねた AUC、生存は分割ごとの C の平均が最大。同じなら少ない方。この選び方は本実装で決めました）。
- **報告**: 外側の分割ごとの値の平均・最小・最大、二値では予測を束ねた AUC。交差検証の値には**信頼区間を付けません**（分割の間の相関のため、素朴な区間は狭すぎる）。テスト集合の値には、AUC は DeLong 法、C-index はブートストラップのパーセンタイルの 95% 信頼区間を付けます。症例数と特徴量の数の比を出し、特徴量の方が多いときは警告します。
- **最終モデル**: 開発集合全体での交差検証で特徴量の数を選び、開発集合全体で作り直します。入れ子の交差検証の値は「この手順全体」の性能の見積もりです。
- 書き出し: 分割ごとの結果、交差検証の予測、選ばれた回数、除いた特徴量・症例、固定ファイル、「方法」の文、再現情報。

ランダムなラベルとランダムな特徴量では入れ子の AUC は 0.5 付近に、分割の前に全データで特徴量を選ぶ（漏れのある）やり方では 0.7 を超えることを、試験で確かめています。

予後・判別・再現性・予測モデルの性能以外のスキル（正則化・ブースティングなどのモデル）は、今後のバージョンで加えます。

## 変化率

変化率 = (後 − 前) / |前| × 100（%）。病変ごとに求めて患者で平均する方法（既定）と、患者で平均してから求める方法を選べます。基準値が 0 の値は欠損にします。

## 開発

```
npm ci
npm run verify   # 型・試験・ビルド（ui.js を生成）
```

参照値の生成（`tools/gen_*_fixture.py`）には Python の numpy・scipy・statsmodels・scikit-learn が要ります。再現性の参照値は pingouin を使うので、システムの環境を変えずに使い捨ての venv で実行します:
`python3 -m venv /tmp/refvenv && /tmp/refvenv/bin/pip install pingouin==0.5.5 && /tmp/refvenv/bin/python tools/gen_reliability_fixture.py`

`ui.js` は生成物です。GRAPHY-Next の `plugins` フォルダに、`plugin.json` と `ui.js` を置くと読み込まれます。
