# Research Stats（GRAPHY-Next プラグイン）

radiomics の研究で、特徴量の表と臨床データを結合してデータセットを作り、**調べたい問いに合わせた解析レシピ**を実行するためのプラグインです。研究用で、診断・治療の判断には使いません。

## いまできること（0.2.0）

メイン画面の「Plug-Ins」メニューの「Research Stats」から開きます。

1. **ファイルを選ぶ**: 特徴量の CSV（複数可。同じ見出しの表は行を連ねます）、臨床の CSV（1 行 = 1 患者）。治療前後の変化率を使うときは、2 つの時点の特徴量の CSV。
2. **列を割り当てる**: 病変・ROI の識別、患者、時間、イベント（0 か 1）、結果ラベル、共変量。
3. **結合の結果を確かめる**: 結合できた患者数、片方の表にしかいない患者、欠損のある列、解析から除く患者と理由。
4. **書き出す**: 結合済みのデータセット（CSV）、「方法」の文、再現情報（JSON: 版・乱数シード・入力ファイルの SHA-256・設定）。

守っていること:

- 欠損は 0 で埋めません。複数病変の平均は欠損を除いて求め、すべて欠損なら欠損のままです。
- 片方にしかいない患者は黙って捨てず、一覧に出します。患者 ID・病変 ID の重複、イベントが 0・1 でない値、時間が正でない値は、直さずに止めます。
- 同じ入力・設定・乱数シードなら、記録も「方法」の文も同じになります。

## レシピ「予後との関係」

特徴量が生存と関係するかを、特徴量ごとに調べます。

- 群の分け方: 中央値（既定）／指定した値／三分位／最適しきい値（log-rank のχ²が最大の値）。最適しきい値は**探索的**で、素の p は探索のぶん小さく出るため、時間とイベントの組を並べ替える検定で補正した p を併記します。各群に残す最小の割合（既定 10%）は実装上の仮定です。
- 各特徴量: Kaplan–Meier 曲線（Greenwood の分散、log(−log) の信頼区間、リスク表）、log-rank 検定、Cox 比例ハザードモデル（同時刻は Efron の近似。群の HR と、標準化した連続値の SD あたり HR）、任意で RMST の差と Mann–Whitney。
- 多重比較: Benjamini–Hochberg 補正（既定）。補正しない探索的な解析は、明示して選びます。
- 多変量: 基準を満たした特徴量と共変量で Cox モデル。臨床因子だけのモデルとの −2 log 尤度の差、C-index、ブートストラップで楽観を補正した C-index（特徴量の選択も毎回やり直します）。
- 書き出し: 特徴量ごとの結果、KM の点列（図を作り直せる数値）、「方法」の文、再現情報。

守っていること: 計算できなかった特徴量は理由を表に出し、p や q は空欄のままにします（0 や 1 にしません）。収束しない・完全分離の Cox は、数値を出さずに理由を出して止めます。

限界: 比例ハザードの仮定は検査していません。多変量モデルの共変量は数値の列だけです（カテゴリは 0/1 などに直してください）。実行が重い設定（最適しきい値 × 多数の特徴量）は、進み具合を出し、取り消せます。

判別・再現性・モデル構築などのレシピは、今後のバージョンで加えます。

## 変化率

変化率 = (後 − 前) / |前| × 100（%）。病変ごとに求めて患者で平均する方法（既定）と、患者で平均してから求める方法を選べます。基準値が 0 の値は欠損にします。

## 開発

```
npm ci
npm run verify   # 型・試験・ビルド（ui.js を生成）
```

`ui.js` は生成物です。GRAPHY-Next の `plugins` フォルダに、`plugin.json` と `ui.js` を置くと読み込まれます。
